# Security Policy

## Reporting a Vulnerability

### How to Report

You can report security vulnerabilities through **GitHub Security Advisory**:
    - Navigate to the [Security tab](https://github.com/re-Director/re-director/security) in the repository
    - Click on "Report a vulnerability"
    - Provide a detailed description of the vulnerability

### What to Include

When reporting a vulnerability, please provide:

- A clear description of the vulnerability
- Steps to reproduce the issue
- Any potential impact
- If possible, suggestions for addressing the vulnerability
- Your contact information for follow-up questions

## Supported Versions

Only the latest version is supported for security updates. Security fixes to older versions will not be backported.

| Version | Supported          |
| ------- | ------------------ |
| Latest  | :white_check_mark: |
| Older   | :x:               |

**Please note:** Before reporting a security issue, ensure you are using the latest version. Security reports for older versions will not be accepted.
